# 📄 Devis Generator

Générateur de devis en HTML/JS — 100% local, aucune donnée envoyée.

## ✨ Fonctionnalités

- Calcul automatique HT / TVA / TTC
- Multi-lignes de prestations
- Export PDF (via impression)
- Sauvegarde locale (localStorage)
- 100% offline — aucune donnée envoyée

## 🚀 Utilisation

Ouvre simplement `devis.html` dans ton navigateur.

Aucune installation requise.
